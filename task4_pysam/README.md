# Summary
task4_pysam.py is a script that accepts a sorted and indexed BAM file as input and counts how many reads in the input BAM file map to Enterococcus faecalis (a genome called "Enterococcus_faecalis_complete_genome").

# Example usage

task4_pysam.py bam_file
where bam_file is a path to a sorted and indexed BAM file

For example:
task4_pysam.py ../task3_snakemake/mapped_reads/reads.sorted.bam
